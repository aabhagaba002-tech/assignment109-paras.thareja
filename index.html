Question 1

RememberingList, Identify

List four primary characteristics of a modern digital computer and identify the key hardware technology associated with each of the five generations of computers.

Four primary characteristics

  1. Speed: executes millions to billions of instructions per second.
  2. Accuracy: gives error-free results when the input and program are correct.
  3. Diligence: works for long hours without fatigue or loss of concentration.
  4. Storage capacity: stores huge amounts of data and instructions and retrieves them quickly.

Other traits include versatility and automation.

Question 2

UnderstandingExplain

Explain the flow of data, instructions, and control signals within the functional block diagram of a computer, detailing the interaction between the CPU, memory unit, and I/O interface.

Input unit→Memory unit↔CPU (ALU + CU)→Output unit
  • Input: the I/O interface converts the user's data and programs into binary and sends them into main memory.
  • Memory: holds the program, the data and the intermediate results. The CPU fetches each instruction from memory.
  • Control Unit (CU): decodes the instruction and sends control signals that tell the ALU, memory and I/O devices what to do and when.
  • ALU: carries out the arithmetic and logic operations on data and returns the result to a register or to memory.
  • Output: the processed result goes from memory through the I/O interface to an output device in a human-readable form.
Data and instructions travel on the data and address buses. Control signals travel on the control bus, so the CU coordinates every unit.

Question 6

EvaluatingAssess, Justify

Assess whether a drum/flatbed plotter or an ultra-high-definition monitor and large-format printer combination is superior for producing civil engineering blueprints, justifying your selection based on line resolution, scalability, and long-term production costs.

CriterionDrum / Flatbed plotterUHD monitor + large-format printer
Line resolutionPen plotters draw continuous vector lines, so lines are crisp and exact.Raster output can show slight stair-stepping on thin lines.
ScalabilityHandles very large sheets (A0 and above) at full accuracy.Large printers also scale well, but a monitor limits on-screen review size.
Long-term costDurable and low cost per drawing, though pens need upkeep.Ink and head replacement raise running costs.
Verdict: a plotter is better for pure engineering blueprints because of line accuracy and low running cost. The monitor and printer combination is better when colour rendering and design review are also needed.

Question 8

CreatingDesign

Design an accessible, hands-free computer workstation tailored for a visually impaired user. Propose a coherent integration of non-visual input devices (such as voice recognition systems and tactile keyboards) with specialized output devices (such as voice response synthesizers and screen readers).

Voice input + tactile keyboard→Computer + screen reader→Speech synthesizer + Braille display
  • Voice recognition system: hands-free commands and dictation, with a noise-cancelling headset microphone.
  • Tactile keyboard: raised marker keys on F and J, with high-contrast, large-print or Braille key labels.
  • Screen reader (e.g. NVDA, JAWS): reads on-screen text, menus and buttons aloud.
  • Voice response synthesizer: text-to-speech gives spoken feedback and confirms every action.
  • Refreshable Braille display: lets the user read text by touch.
  • Optional extras: a scanner with OCR to read printed pages aloud, and audio cues for alerts.
Voice and keyboard give two ways to input. Speech and Braille give two ways to receive output. This keeps the workstation usable even if one channel fails.
